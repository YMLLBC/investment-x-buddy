# 投资 X Buddy 实施计划

## 全局约束
中文优先，文件保存在D盘；不执行交易、不输出确定涨跌/收益承诺或直接买卖建议。密钥只在服务端，排除源码/日志/浏览器/提交包。每阶段更新 STATUS、STAGES、VALIDATION。公开构造数据回放与访问码保护的真实研究。

## Task 1 基础与文档
Sites Vinext React/TypeScript，D1持久存储，测试与文档；独立目录，开发分支work/investment-buddy。定义共享types和接口。生成并检查migration，禁止运行时创建表。

## Task 2 Harness
纯函数状态机/工具注册/审批/预算/停止/恢复/幂等检查点/压缩/引用校验/脱敏导出；先失败测试再实现。内核不读密钥和数据库。

## Task 3 服务与工具
DeepSeek Responses规划和解读，扶摇检索/快照/历史/财务/估值/日历，iFinD公司信息/公告/新闻。服务端会话所有权隔离，D1版本控制与任务租约；一次续跑执行有界任务，刷新恢复。记忆须显式确认。

## Task 4 工作台
深色中文研究工作区：线程导航、目标输入、计划审批、任务动态状态、对比图表、证据抽屉、报告、Markdown/JSON导出、记忆管理、活动与成本；响应式与键盘访问。

## Task 5 验证与交付
npm test/typecheck/build/test:e2e全部成功；至少一条完整真实研究；缺失/接口失败/拒绝/停止/恢复/预算/注入边界；代码审查。部署返回succeeded及URL；GitHub权限可用则发布；README、AI/测试记录、<30MB zip，密钥扫描。

## 默认限制
最多24个工具任务、4次模型生成；金融接口45秒，模型120秒；瞬态失败最多2次重试，429尊重Retry-After，401/403和参数错误不重试。报告数值由代码计算；模型输出须引用证据。费用按usage和配置价格估算，未知计费显式标记，预算/停止/无效计划必须明确暂停。公开示例不发付费请求。
